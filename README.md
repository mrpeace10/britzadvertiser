# Britz Advertiser

Website for [britzadvertiser.co.uk](https://www.britzadvertiser.co.uk): local digital marketing, websites and web hosting.

Plain HTML and CSS, no build step. Upload the files as they are to the web root.

## Pages

| File | Page |
|---|---|
| `index.html` | Home |
| `services.html` | Services and FAQ |
| `portfolio.html` | Our work |
| `contact.html` | Contact form |
| `terms.html` | Terms & conditions |

## Structure

```
css/base.css        shared header, footer, buttons, type
css/home.css        home page
css/services.css    services page
css/portfolio.css   portfolio page
css/contact.css     contact page
css/terms.css       terms page
js/main.js          mobile menu, footer year, contact form (opens the visitor's email app)
assets/img/         logo and images
```

Client sites live in their own repositories, e.g. Rothwell Town Friar at
[rothwelltownfriar.britzadvertiser.co.uk](https://rothwelltownfriar.britzadvertiser.co.uk/).
